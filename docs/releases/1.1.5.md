# RestoKit 1.1.5 (2026-11-21)

Replaces 1.1.4 as the live kit. The previous version stays downloadable for a while.

Live file: `resto_kit_1.1.5.json` (`meta.version` 1.1.5). Sign up for the kit at [resto-kit.com/get-the-kit](https://resto-kit.com/get-the-kit). Agents should check [resto-kit.com/kit/latest.json](https://resto-kit.com/kit/latest.json) on first load in a session.

This page is the public update record and change log for 1.1.5. There are no new field rules in this release. It fixes structure and consistency problems found in a full review of 1.1.4.

## Hazard testing on the scope sheet

- The hazard testing line on the billable scope sheet now matches the kit's hazard rule. Building age is a prompt, not a clearance: suspect material of any age is sampled or presumed. Pre-1978 paint falls under the EPA renovation rule: test it or presume lead. Check current state and local rules.

## Morning note and Day Forward

- Day Forward was scrapped earlier. A leftover section still called it the standard job plan format. It is removed, and what's next lives in the living Mitigation Scope notes.
- The morning note after a job talk is still delta only (decisions, today's work, who's assigned, holds that changed). Its rules now live in one place instead of two.

## Daily log template

- Customers are named by role (homeowner, tenant, adjuster), with no customer-identifying detail.
- The log records a job reference (claim or job number) instead of a street address.
- Company-specific timesheet limits are replaced by the company's own timesheet rules.

## Structure and consistency

- Scoping links are clean section links, so the website expands them into the section text instead of showing a short code.
- The material decision principles, the company gap lines, and appliance handling have clean, stable links.
- Old version stamps and a leftover transcription note are out of the scope sheet.
- Two sections got titles and descriptions, and sections that overlap say what each one covers.
- A few small wording fixes: a colon instead of a dash in the demo order title, plain section names instead of file paths, and the insurance guidance now says to explain technical details plainly with the readings and photos.

## Checks

These were run on the 1.1.5 file before it was published:

- The kit structure check passed with no failures or warnings.
- The billable catalog check passed (18 of 18).
- Every section link resolves.
- This version is built on 1.1.4, which remains available.

## What the website should reflect

- Live kit version is 1.1.5. The previous downloadable version is 1.1.4.

License, limitations, and the update check are unchanged. RestoKit aligns with the principles of IICRC S500 and S520. No version bump beyond 1.1.5 unless the owner says so.
